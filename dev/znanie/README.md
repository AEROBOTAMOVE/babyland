# 📚 ЗНАНИЕТО НА БЕЙБИ ЛЕНД · суровина за помощничките

Тук се събира ВСИЧКО, което една българска майка може да попита или да иска да знае:
наука и медицина, практика и права в България, традиции, бабини деветини, култура, език.
От тези файлове после се правят карти за помощничките (js/kb.js) — на спокойствие и с мярка.
Папката НЕ се качва в приложението (dev/ не се строи).

## Подредба
`dev/znanie/<NN-тема>/<подтема>.md` — един файл на подтема, 1–3 страници, гъсто.

## Формат на всеки запис (в един файл може да има много записи)
```
## <Заглавие — както би го нарекла майка>
**Накратко:** 2–4 изречения, най-важното.
**Подробно:** конкретика — числа, срокове, стъпки, по месеци/седмици, български реалии.
**Бабите казват:** поверието/народният съвет, ако има — и какво казва науката за него
  (безвредно / полезно / ⚠️ опасно и защо).
**Кога към лекар:** само за здравни теми — ясни признаци, без плашене.
**Как пита майката:** 3–6 реални формулировки, както пише на телефона
  („не иска да спи по обяд“, „кога се пуска водичка“, „бебето ми се поти по главата“…).
**Източници:** URL-и (тип: официален / медицински / наръчник / форум / фолклор / медия).
```

## Правила
- Пиши СЪС СВОИ ДУМИ. Без копирани абзаци; цитат — до 15 думи, в кавички.
- ПЕСНИ (вкл. народни и приспивни): САМО заглавие, жанр, откъде е, за каква възраст — НИКАКВИ
  текстове. Авторски стихове и приказки — заглавие, автор, сюжет със свои думи. Гатанки и
  поговорки — може (кратки, народни, не са песни).
- Форумите (BG-Mamma, групи) — само за ТЕМИТЕ и ЕЗИКА на майките: без имена, никове, лични истории.
- Всяко твърдение за здраве — с източник. Народното се отбелязва като народно.
- Български реалии винаги: НЗОК, НОИ, МЗ, ДКЦ, личен лекар, ясли, наредби, суми, срокове
  (с година на източника — сумите се менят).
- Записвай файла ВЕДНАГА щом подтемата е готова (рестартът не прощава).
