## Картата (`karti_<ключ>.json` — масив от обекти)
```
{ "id": "<твоят ключ>-<кратко-латиница>", // напр. zn1a-pupche-pada; латиница-кебаб, 3–40 знака, НОВ (Grep в js/kb.js)
  "room": "Моето бебе",                   // точно една от: Бременност · Моето бебе · Здраве и SOS · Захранване ·
                                           // Развитие и игри · Дневник на мама · Жената в мен · Инструменти · Лабораторията
  "от": 0, "до": 12,                       // по желание: месеци на бебето (бременност: отрицателни седмици до раждането, ≥ −9 мес.)
  "title": "Както би го нарекла майка",
  "core": "Отговорът: 60–150 думи, топло, ясно, конкретно, български реалии.",   // под 190 думи
  "tip": "💡 Едно практично нещо, което да направи днес.",
  "follow": "Кога към лекар / какво следва. При опасност изречението ЗАПОЧВА с 🚨 и е най-отпред.",
  "keys": ["как пита майката", "…"],      // ≥ 12 ключа: малки букви, 2–6 думи, както пише на телефона;
                                           // 2–3 на латиница (шльокавица); БЕЗ голи общи думи („сън“, „6 месеца“,
                                           // „на колко месеца“, „готово ли е“) — те крадат чужди теми
  "chips": ["id-на-съществуваща-карта"]   // 1–3, само СЪЩЕСТВУВАЩИ id (Grep в js/kb.js)
}
```
Текстът: САМО типографски кавички „…“ — НИКАКВИ прави ' или " (и в ключовете). Без латински мерки до число (пиши „5 мл“).
