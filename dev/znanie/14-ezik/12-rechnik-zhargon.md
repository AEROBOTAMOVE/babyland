# 14 · ЕЗИК · Речник на майчиния жаргон и разговорните думи

Как се чете: **дума** — значение; в скоби: регистър, регион, надеждност.
Надеждност: без знак = широко известна българска дума/употреба (общо езиково познание — ПРЕДПОЛОЖЕНО, не проверено срещу корпус в тази сесия); (?) = вероятно/непостоянно/регионално — не разчитай без проверка; (BGM) = белег е видян в ЗАГЛАВИЕ на тема в BG-Mamma чрез търсачка в тази сесия.
Правило за помощничката: РАЗБИРАЙ тези думи, но не ги връщай обратно на майката като свои („цица“, „ака“, „пишка“) освен ако тя сама ги е употребила; тогава огледай нейния регистър, без да преиграваш.
Академичен фон (заглавия, не пълни текстове — пълният текст не е четен): Биляна Тодорова, „Езикът във форумите за майки в социално-семиотична перспектива“ (2009) и „За някои специфични лексикални употреби във форумите на bg-mamma“ (2013, сб. „70 години българска академична лексикография“, с. 438–446) — резюмето отбелязва два принципа на този тип общуване: лексикална икономия (съкращения) и стремеж към изразителност. Руско сравнение (не за България): майчините форуми слагат умалителни, съкращения за хранене/цикъл и заместват местоимения с имена (виж mel.fm статията).

## 1. Думи към бебето и от бебето (звукоподражания, ласкателни)
- **ам-ам / ям-ям** — храна, яденето; „да правим ам-ам“.
- **пи-пи** — (?) пиене на вода/сок; „пи-пи“ се среща и като дет. за уриниране — смисълът е по контекст.
- **нани / нанка / на нани** — сън, лягане; „правим нани“, „нани-нани“ (приспиване).
- **спинка / спинкам** — спане (ласк. -инка); „време за спинка“.
- **ака / акам / акане / акал ли е** — голяма нужда, изпражнение; „направи ака“, „цвета на акото“, „акало“ (?).
- **пишка / пишкам / пишане** — уриниране; „иска пишка“; също полов орган на момче (дет.). Групово: „пишки“ = уринирания.
- **газчета / пръдня / пуска газ** — газове; „газчетата го мъчат“.
- **ригане / оригва се / ригна** — оригване след хранене; „оригвам го“ = тупам по гърба.
- **бълва / връща / избълва / повръща** — върната храна; „връща“ = малко количество, „бълва“ = повече, „повръща“ = по-сериозно (по-строг регистър = по-голяма тревога).
- **цица / цицка / цицам / цицане** — гърда и кърмене (разг., с нежност); „иска цица“, „цицка му е всичко“.
- **гушкам / гушка / гушни** — прегръщам, държа в прегръдка.
- **тупам / тупа** — потупване по гърба (оригване/успокояване).
- **ку-ку / тук-тук** — игра „къде е бебето“.
- **агукам / гука / бърбори** — първите звуци; „гукане“ (около 2–3 м.), „бърборене“ (около 6 м.).
- **мама-ма, та-та-та, ба-ба** — първите срички; „казва мама“ често се брои за дума по-рано от лингвистичната норма.
- **бибе** — (?) непостоянна дума: ласк. за „бебе“ или за шише; по-стабилни са „шише“, „биберон“. Проверявай контекста.
- **бебенце / бебче / бебка / бебок / бебо** — ласк. за бебе. „Бебенце“ често се пише с правописни грешки (виж 14-pravopis).
- **мъник / мъниче / мъничко / мъникът** — малко дете (ласк.); „мъниче моето“.
- **малкия / малката / малкото** — детето (по пол), често без име.
- **дребосък / дребосъче** — дете (шеговито); **палавник / палавница / дяволче** — подвижно, непослушно.
- **слънчице / сладурче / съкровище / миличко / златно / пиленце / принцеса / принц / зайчо** — обръщения.
- **мамо / мамче / мама** — обръщение на майката към детето или (по-рядко) към себе си: „мама е тук“. Майките често говорят в трето лице за себе си.
- **тати / татко / таткото** — бащата; „тате“ = обръщение.

## 2. Хранене и кърмене
- **кърмя / кърмене / кърмачка** — хранене с гърда (често „кармя/кормя/кърмя“ — виж 14-pravopis).
- **кърма / майчино мляко** — течността; съкращ. (?) „ММ“.
- **мляко** — общо: може да значи и адаптирано (в контекст „даваме му мляко“); „кърма“ е отделено.
- **адаптирано / адаптирано мляко** — формула; (?) „АМ“; „сухо мляко“ (?), „мляко на прах“ (?). „Смес“ е руска калка — рядко.
- **шише / шишенце** — шише за мляко. **биберон** — (1) накрайникът на шишето, (2) разговорно и „залъгалка“ — двусмислено, пита се от кое иска да говори.
- **залъгалка / тапа (?)** — пустышка за смукане.
- **захващане** — как бебето хваща гърдата (латч). **кластър** — бебето суче на кратки интервали час-два.
- **виси на гърдата / виси на цицата** — суче непрекъснато.
- **налети гърди / налетост** — болезнено напълнени. **дойде ми млякото** — началото на пълното мляко (на 2–5 ден).
- **мастит** — възпаление; **запушен канал**; **буца в гърдата**; **млечница** — (1) гъбичка в устата на бебето (бял налеп), (2) на зърното.
- **юздичка / къса юздичка** — (?) уздечка под езика; „клиничното“ име е анкилоглосия.
- **изцеждам / изцедено мляко / помпа / помпичка** — изцеждане; „медела“ и „авент“ — родови имена за помпи/шишета (марки).
- **лактационна криза / криза на растежа / скок на растеж** — временно намаляване/промяна на млякото; (BGM: „Лактационни кризи“ ?topic=5186).
- **отбиване / отбивам** — спиране на кърменето; **нощно отбиване** — спиране на нощните хранения.
- **захранване (зарханване — грешка)** — въвеждане на твърда храна. **пюре / пюренце / пюрета** — смачкана храна; **каша / кашичка** — зърнена; **бурканче / бурканчета** — готова храна в буркан.
- **БЛВ / самозахранване / парченца / пръстова храна** — метод „baby-led weaning“; чете се „блв“.
- **лъжичка / лъжица**; **лигавник / лигавниче**; **чашка със сламка / чашка с накрайник**; **столче за хранене / хайчер (?)**.
- **злояд / злоядо / злоядата** — дете, което яде малко/избирателно (BGM: „ЗЛОЯДО ДЕТЕ“ ?topic=5811). **стиска устата, плюе, гребе** (?) — отказва/разхвърля.
- **кисело / извара / сирене / кашкавал** — традиционни млечни; **бисквити за бебета / сухар** — ядат се с поглед „полезни ли са“.
- **баничка / мекица / питка** — български тестени храни; **питка** също на прощъпулник.

## 3. Сън
- **дрямка / дрямки** — дневен сън; „една дрямка“, „2 дрямки“.
- **заспива на гърда / на ръце / в количка / в колата** — условия, при които спи.
- **приспивам / приспиване / люлея / люлеене** — действия.
- **съвместен сън / спим заедно / в нашето легло** — co-sleeping; **кошарка до леглото** — „кошара-приставка“.
- **повиване / повивам** — увиване; **повивалник** — маса/плот за преповиване; **преповивам** — сменям пелената (!) — двусмислено: „преповиване“ = смяна на памперс.
- **чувалче (за спане)** — спално чувалче; **бял шум** — звук за сън; **нощна лампа**.
- **регресия (на съня)** — период, в който бебето започва да спи по-лошо (прието „4-месечна регресия“); не е диагноза, майките я ползват като обяснение.
- **скок (в развитието / в растежа)** — период на повишена капризност и сън/хранене различни; „скок на 8 седмица“, „скок на 12 седмица“.
- **стряска се / трепва** — рефлекс на стряскане насън.
- **ферберизиране / Фербер** — метод на оставяне на плач за кратко; **оставям да се наплаче** — разговорно за „cry it out“; **сън тренинг / приучаване към сън** (?).
- **режим** — ред на сън/хранене/будност; „слагам го на режим“.

## 4. Памперси, къпане, дрехи, вещи
- **памперс / памперси** — еднократна пелена (марка станала родово име). **пелена / пелени** — (1) разговорно памперс (в заглавие на roditel.bg: „…да премине от пелени към гърне“ — тук „пелени“ = памперси), (2) текстилна/муселинова. **гащи-памперс / памперс гащи** — „pull-ups“.
- **подсичане / подсича го / червено задниче** — обрив от пелена. **бепантен, деситин** — кремове (марки, родови).
- **мокри кърпички / салфетки / кърпички** — мокри бебешки кърпи.
- **къпане / ваничка / вана / корито (?: традиционно корито)** — къпане.
- **дрешки / дрешчици / бодита / гащеризон / ританки (?) / чорапки / шапчица / ръкавички / обувчици / пижамка** — дрехи в умалителен вид. **боди** — бебешка риза с копчета отдолу.
- **муселин / муселинова пелена** — тънка памучна кърпа.
- **количка / комбинирана количка / проходилка / ходилка (?)** — превозно средство.
- **столче за кола / кошница за кола / „кенгуру“ / слинг / ергономична раница** — носене.
- **кошара / кошарка / люлка / шезлонг / шезлонгче / мобил (над кошарата)** — места/уреди за бебето.
- **бебефон** — монитор за бебе.
- **гърне / гърненце / накрайник (за тоалетна) / стъпенка** — вещи за отпелюшване.

## 5. Здраве (народни и разговорни думи)
- **колики / колика** — плач и коремни спазми; най-често между 2-ра седмица и 3–4 месеца; народно „газчета“ и „коремче“.
- **диатеза** — (народно) обрив по бузите/тялото от храна/кожа; не е медицински термин.
- **изби го / избива му** — обрив.
- **млечна краста** — жълти люспи по главата на бебе; (?) терминът е народен.
- **жълтеница / жълто е / билирубин / на лампа / фототерапия** — пожълтяване на новороденото.
- **пъпче / пъпа / пъпната кичурка / пъпна херния / „килце“** — пъп; „кила“ = херния (народно).
- **родниче** — фонтанела; „родничето му пулсира/е хлътнало“.
- **сополи / сополив / запушено носле / хрема** — хрема; **аспиратор / помпичка за нос** — изсмукване; **физиологичен разтвор / морска вода / аквамарис / физиомер** — разтвори за нос.
- **хърка / хрипти / свири му / лае (кашлица) / задушава се** — звуци при дишане/кашлица.
- **температура / температурка / гори / топло му е / вдигна** — треска; **термометър в дупето / под мишницата / в ухото / челен**.
- **свещичка / сироп / капки / антибиотик** — форми на лекарства.
- **нурофен / калпол / ефералган / парацетамол / ибупрофен** — болкоуспокояващи/понижаващи температурата (родови имена: нурофен = ибупрофен, калпол = парацетамол).
- **еспумизан / сабсимплекс / „еспу“ (?)** — симетикон (за газове).
- **бепантен** — крем за пелена (ако не е за пелена, ползва се и за зърна).
- **имуностимулатор / имунитет / „слаб имунитет“** — майчиното обяснение за честите болести.
- **пробиотик / витамин Д / желязо** — добавки.
- **зъбки / зъби се / никнат / реже зъби / пробива зъбче** — никнене; **венци**; **гризалка**; **лиги / лигави се**; **дентинокс (?)** — гел.
- **ваксини / имунизации / дози / задължителни / платени** — ваксини; **хекса / хексавалентна**, **пневмококова / превенар (?)**, **ротавирус**, **ММР**, **БЦЖ** (белегът), **хепатит**; **ваксинална книжка / имунизационна книжка / здравна книжка / детска книжка** — документи.
- **личният / личната / педиатърът / докторката / детският лекар / патронажната сестра / патронажката** — лекари/сестри. **ДКЦ / поликлиника / спешното / инфекциозно / детска болница** — места.
- **глътна / задави се / удари главата / падна** — инциденти.
- **шарка / пилешка шарка / скарлатина / морбили (дребна шарка) / ръка-крак-уста** — детски болести.
- **стомашен вирус / ротавирус / разстройство / течно ака / пуска вода** — диария (народно).
- **запек / напъва се / червенее** — запек/напъване.
- **млечница в устата** — бял налеп (виж 2).
- **обрив от пелена / гъбичка (?)** — подсичане и гъбична инфекция.

## 6. Развитие и поведение
- **обръща се / преобръща се / сяда / седи / пълзи / лази / лазене / ходи / проходи / крачи / държи се** — етапи; **прощъпулник** — празник на първите стъпки с питка.
- **гука / агука / бърбори / казва мама / проговаря / сочи** — реч.
- **перцентил / перцентили / „на 3-ти / на 50-ти“** — място в растежните таблици; (?) майките често го разбират като оценка.
- **закъснява / изостава / бавно е / по-малко от другите** — сравнение.
- **инат / инатлив / инатчия** — упорство; **капризен / капризничи / вкисва се (?)** — недоволство.
- **вкиснато** — (контекстно, 3 значения): (а) мляко/храна, която се е развалила („изцеженото вкисна“); (б) вкисната физиономия/настроение у дете („вкиснато е“, „вкисва се“ = мрънка, недоволство); (в) миризма на вкиснало по кожата/дрехите (след повръщане, на гънките) — питай кое има предвид.
- **вкисва се / вкиснат** — недоволен, мрънкащ.
- **истерия / истерички / нервен срив / пада на земята / тропа / реве** — гневни изблици.
- **фаза** — „във фаза на НЕ“, „фаза на хапане“ — майчино обяснение за поведение.
- **криза (на 1 г. / на 3 г.)** — преломен момент в поведението; „терибъл туус / ужасните двегодишни“ — прекален сарказъм.
- **хапе / бие / щипе / дърпа коса / рита** — агресия; **ревнува** — ревност.
- **лепне / залепва се за мен / не ме пуска** — привързаност/раздяла.
- **отпелюшване / отучаване от памперс / без памперс** — махане на памперса; **напишква се / мокри се / инцидент** — неуспех.
- **нервен / нервничи / плаче без причина** — майки често не различават „без причина“ от „не знам причината“.
- **хиперактивен / „не стои на едно място“** — прекалено подвижен (за малко дете често нормално).

## 8. След раждането (майката)
- **кървя още / лохии (?)** — следродилно кървене.
- **шевовете / шевчето** — разрез/разкъсване.
- **бейби блус / блус** — преходна тъга; **следродилна** — съкратено от „следродилна депресия“ („имам следродилна“).
- **диастаза** — разтягане на коремните мускули. **провиснал корем / стрии** — телесни промени.
- **пада ми косата / окапва** — нормално изпадане на коса.
- **напукани зърна / капачки (силиконови накрайници)** — кърмене.
- **месечни след раждане / контрацепция** — цикъл/предпазване.
- **лактационен консултант (ЛК?) / Ла Лече** — помощ за кърмене.
- **психолог / психиатър / „да говоря с някого“** — търсене на помощ; често с вина.

## 9. Пари, документи, институции
- **майчинство / майчинските / 410 дни / втората година** — отпуска и парите.
- **болничен (по бременност / за дете / обикновен)**.
- **НОИ, НАП, НЗОК (касата), общината, кметството, ДСП/АСП („Социалните“), Бюрото по труда, ТЕЛК**.
- **еднократната / детски / месечни / надбавки / облекчение / данъчното**.
- **акт / акт за раждане / удостоверение / ЕГН / лична / здравна книжка / епикриза / бележка**.
- **частен лекар / частна градина / частна клиника / „платено“**.
- **личен лекар на детето / смяна на личния / записване при личен** — регистрация.

## 10. Роднини и социални роли
- **мъжът ми / съпругът ми / половинката ми / таткото / бащата на детето / бившият / той** — партньор; без име = често напрежение.
- **свекърва / свекървата / тъща / зълва / снаха / баба му / дядо му / баби / кума / кум / кръстник** — роднини; **свекърва ми** е най-често „тема“.
- **меси се / бърка се / раздава акъл / командва / подкопава ме** — конфликт с роднини.
- **бавачка / детегледачка / лелка** — външен човек за гледане.

## 11. Ясла и градина

## 12. Съкращения и форумни белези
- **г.с., гс, седм., мес., дн., кг, гр, мл, см** — мерки (често без точка/интервал: „3кг“, „2мес“, „40мл“).
- **НОИ, НЗОК, НАП, ЕГН, ТЕЛК, АСП, ДСП, ДГ, ЦДГ, ДКЦ, УНГ, КТГ, ПДР (?), БЛВ, ММ (?), АМ (?)** — общо.
- **ЛС** — (?) лично съобщение („пишете ми в ЛС“).
- **Б / *Б*** — бременна (заглавие на тема в BG-Mamma: „Кога на лекар, след закъснението? *Б*“, ?topic=6152) (BGM).
- **мами / момичета / мамчета / мамички / мамита (?)** — обръщения към другите потребителки.
- **помощ! / спешно! / моля / някоя / имало ли е / минавала ли е / случвало ли ви се** — зачини на въпроса.
- **нормално ли е / само при мен ли е / дали е / и вие ли / къде бъркам / до кога / от кога** — формули на успокоение.
- **))) / :( / :D / хаха / хах / ххх / мдаа / еее / ъм / ъхъ / ооо** — интернет-стил.

## 14. Фрази, които носят подтекст (не са буквален въпрос)
- **„нормално ли е“** — търси успокоение; често вече е прочела, че е нормално.
- **„само при мен ли е така“** — самота, сравнение.
- **„някоя минавала ли е през това“** — търси опит, не информация.
- **„просто питам“, „за напред“, „чела съм“** — любопитство, няма спешност.
- **„не знам какво да правя“, „не мога повече“, „на ръба съм“** — майчино изтощение; първо слушане.
- **„лоша майка съм“, „аз ли съм виновна“** — вина; не отговаряй с „не си“ механично.
- **„всички ми казват…“, „те са ни гледали така…“** — натиск от роднини.
- **„ние“ вместо „аз“** („ние не спим“) — майка и дете като едно; **„той“ без име** (за партньор) — напрежение.
