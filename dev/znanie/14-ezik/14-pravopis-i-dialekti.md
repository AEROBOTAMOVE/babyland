# 14 · ЕЗИК · Правописни грешки, хомоглифи, диалекти и региони

Произход и надеждност:
- ПОТВЪРДЕНО в сесията: ятовата граница — на изток от нея „бял, бели“, на запад „бел, бели“ (bg.wikipedia „Български диалекти“, прочетена с WebFetch). От това правило са изведени двойките мляко/млеко, хляб/хлеб, няма/нема, трябва/требе, цял/цел, лято/лето, дядо/дедо, сняг/снег — логично следствие от правилото, не изброено на самата страница.
- ПРЕДПОЛОЖЕНО (езиково познание на автора, без корпус): всички примери за правописни грешки, хомоглифите, фонетичното писане и регионалните частици (ке/ше, оти, дека, шо, ма, ле, бре…). Страницата за диалектите изрично НЕ съдържа тези думи.
- Примерът „кърмя → кармя/кормя“ от задачата е в таблица 1.1 като тип ъ/а, ъ/о.

Принцип за помощничката: НЕ поправя майката и не показва, че е забелязала грешка. Разчита смисъла; в собствения си отговор използва правилната форма, без коментар.

## 1. Правописни грешки, типични за бързо писане на телефон (грешно → правилно)

| Грешно | Правилно | Тип |
|---|---|---|
| кармя | кърмя | ъ→а |
| кормя | кърмя | ъ→о |
| кърмение | кърмене | двоене на гласна |
| пидиатър | педиатър | е→и |
| педятър | педиатър | пропуск/смесване |
| темпиратура | температура | е→и |
| парацитамол | парацетамол | е→и |
| антибиотек | антибиотик | и→е |
| сируп | сироп | о→у |
| калики | колики | о→а |
| лякарство | лекарство | е→я (хиперкорекция) |
| бебинце | бебенце | е→и |
| пампърс | памперс | е→ъ |
| залагалка | залъгалка | ъ→а |
| зарханване | захранване | метатеза |
| имунезация | имунизация | и→е |
| млешница | млечница | ч→ш |

| Грешно | Правилно |
|---|---|

| незнам | не знам |

| на края (като „накрая“) | накрая |

### 1.6 Предлози в/във, с/със
| Грешно | Правилно |
|---|---|
| в Варна, в Враца | във Варна, във Враца |
| в Фейсбук | във Фейсбук |

### 1.7 Съм / сам, ми / ме
| Грешно | Правилно | Забележка |
|---|---|---|
| аз сам уморена | аз съм уморена | „сам“ = alone; „съм“ = to be |
| ми е страх / ме е страх | и двете форми са допустими по смисъл | не поправяй |

### 1.8 Числа, мерки, дати (как се пишат)
- „3мес“, „3 мес.“, „3 месеца и половина“, „3.5 мес“, „3,5“.
- „2г.“, „2 год.“, „на годинка“, „на 1 г.“.
- „7+3“, „7 г.с.“, „7гс“, „7-ма седмица“, „седмица 7“ (седмица + дни).
- „39,5“ / „39.5“ / „395“ (липса на запетая); „37 и 5“ / „37.5“.
- „4мл“, „4 мл.“, „4ml“.
- „2 кг 300“, „2,3“, „2 и 300“ (кг и грамове).

## 2. Хомоглифи — латински букви вътре в кирилски думи (важно за машинното търсене)
Телефонът или копирането смесват азбуки. Дума, която изглежда правилно, но не се намира при търсене, вероятно съдържа латинска буква вместо кирилска. Нормализирай преди сравнение.
| Латинска | Кирилска | | Латинска | Кирилска |
|---|---|---|---|---|
| a | а | | p | р |
| e | е | | c | с |
| o | о | | x | х |
| y | у | | k | к |
| m | м | | t | т |
| H | Н | | B | В |
| T | Т | | M | М |
| A, E, O, P, C, X, K | А, Е, О, Р, С, Х, К | | | |
Пример: в „диша“ с латинско a (U+0061), в „лекар“ с латинско a, в „много“ с латинско o — изглеждат като кирилица, но са други кодови точки.
Автоматична проверка (в тази сесия): всеки от тези файлове е проверен с регулярен израз за думи със смесена азбука; резултатът е в 00-izvori-i-metod.md.

## 3. Стил на писане с технически последици
- Без запетаи: „бебето ми е на 2 месеца не иска да спи какво да правя“ — не разчитай на пунктуация; разделяй по въпросителни думи („какво“, „дали“, „как“, „кога“, „колко“).
- Без главни: всичко малки; **ВСИЧКО ГЛАВНИ** = силна емоция.
- Удължени букви: „помооощ“, „мнооого“, „спешнооо“ → свий повторенията (3+ → 1) преди търсене, но запази флага за емоция.
- Повторени знаци: „!!!“, „???“, „…“ — флаг за тревога/нерви.
- Усмивки: „))))“, „:(“, „:D“, „хах“, „хаха“ — флаг за тон, не са въпрос.
- Липса на интервал след запетая/точка: „здравейте,имам въпрос“ — разделяй и по „.,!?“.
- Автокорекция: на телефон при шльокавица клавиатурата може да смени думата с различна (виж 13-shlokavitsa).
- Съкращения без точка: „г.с.“, „гс“, „мес“, „дн“, „седм“, „кг“, „гр“, „мл“, „см“.
- Опечатки: разменени съседни букви („бебтео“, „млякот“), прескочена буква („бебто“), двойни („бебеето“).

## 5. Родствени и ласкателни думи, различни по региони/семейства
(Всичко — ПРЕДПОЛОЖЕНО, без корпус; използвай само за разбиране.)
- **Баба/дядо:** „баба“, „бабо“, „бабичка“; „дядо“, „деде“, „дедо“.
- **Майка/баща към детето:** „мама“, „мама е тук“, „мамо“, „татко“, „тате“, „тати“.
- **По-голямо дете:** „кака“ (по-голяма сестра), „батко“ (по-голям брат; „бате“ в някои краища), „голямата/голямото“.
- **Обръщения към бебето:** „слънчице“, „миличко“, „мъник“, „хлапе“ (по-големи), „зайче“, „пиленце“, „златно“.
- **Архаични обръщения на роднини в цитати на майките:** „чедо“ (?) — майките го използват, когато предават думите на бабата („каза ми, чедо…“).

## 6. Как да се чете „регионалната“ майка
- Ако пише „нема“, „требе“, „оти“, „дека“ — вероятно от Западна България/Македония; не поправяй.
- Ако пише „шо“, „бе“, „бре“, „мари“ — може да е от юг/Тракия/Родопи/Пловдив; тонът е близък, не груб.
- Ако пише „млеко“, „хлеб“ — възможен диалект или бърз правопис; дръж и двата варианта в речника на търсенето.
- Диалектът е сигнал за близост и неформален регистър: отговорът може да е по-топъл, но НЕ имитира диалекта.
