# 🎈 Бейби Ленд — помощникът на мама

**Живо: https://aerobotamove.github.io/babyland/**

Офлайн приложение за майки — от бременността до третата година.
Отваря се от браузъра и се инсталира на телефона като приложение.
След първото зареждане работи **изцяло без интернет**.

## Какво има вътре

| | |
|---|---|
| стаи | **9**, всяка със своя помощничка |
| база на знанието | **383** записа |
| библиотека | **825** статии, **218** свързани директно с чата |
| флагове за спешност | **585** — за бебето, за майката, за бременността, при загуба, при насилие в дома |

## Как се инсталира на телефон

1. Отвори линка в браузъра на телефона
2. Меню → „Добави към началния екран"
3. Готово — иконата стои като на всяко приложение

## Какво е проверено преди пускането

- **94** реални майчини въпроса → **0** без отговор
- контраст на **6 екрана × 2 теми**, ~9000 текста — нула под прага за четимост
- **офлайн**: сървърът беше спрян и приложението продължи да работи
- **36** проверки на флаговете в двете посоки — гърми когато трябва, мълчи когато не трябва

## Обещания към майката

- никакви дози на лекарства — те са разговор с нейния лекар
- нищо, което брои какво НЕ е направила
- нищо, което приема за дадено партньор, пари, помощ или свободно време
- празно поле не е доказателство: „нямам записано" ≠ „няма"
